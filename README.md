# RENAD — A Universe Made for You

موقع رحلة تفاعلية شخصية يعمل كصفحة ثابتة بلا backend أو اعتماديات بناء. الواجهة تستخدم HTML وCSS وJavaScript modules، مع نجوم مرسومة على Canvas ومؤثرات CSS خفيفة لتعمل حتى لو WebGL غير متاح.

## التشغيل محليًا

من داخل هذا المجلد شغّل خادم ملفات ثابتة، لأن المتصفح يحتاج HTTP لتحميل JavaScript modules:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`. لا يوجد تشغيل تلقائي للصوت. اضغطي زر الموسيقى لتشغيل الأغنية.

## النشر على GitHub Pages

انشر محتويات هذا المجلد كما هي. الروابط للأصول نسبية حتى تعمل صفحات الموقع تحت اسم مستودع مثل `/renad/`. لا تغيّر حالة القفل في كبسولة الوقت على أنها حماية: القفل يعمل في الواجهة فقط، والمحتوى موجود في JavaScript ويمكن الوصول إليه من المتصفح.

## التواريخ وتوقيت القاهرة

كل التواريخ المرجعية في `src/js/config.js`. تُحوّل الأوقات المحلية إلى لحظات UTC باستخدام `Intl.DateTimeFormat` مع `Africa/Cairo` وقراءة فرق التوقيت الفعلي؛ لا يوجد offset صيفي ثابت. بداية الكلام محسوبة من منتصف الليل تقريبًا لأن الساعة غير معروفة. تاريخ الارتباط هو 21 أكتوبر 2026 الساعة 6:21 مساءً. عيد الميلاد هو 25 فبراير 2010، والعدّ التنازلي يتجه إلى أقرب عيد ميلاد قادم.

## تخصيص المحتوى والأصول

عدّل الأسماء، الألقاب، التواريخ، الوعود، الصور، الأغاني، وصفحات الرسالة من `src/js/config.js`. ملف الأصول والمقاسات المقترحة في [MEDIA_GUIDE_AR.md](MEDIA_GUIDE_AR.md). المشاهد تحفظ آخر موضع وخيار تقليل الحركة في `localStorage` عند توفره.

## ملاحظات إمكانية الوصول

- تنقل لوحة المفاتيح متاح عبر الأزرار، وتُغلق نافذة الصور بزر Escape.
- يوجد رابط تخطٍ للمحتوى، وتسميات للأزرار والصور، وحالات حية للرسائل المتغيرة.
- خيار تقليل الحركة واحترام `prefers-reduced-motion` مدمجان.
- الصور في المعرض تحمل `loading="lazy"`، بينما الشعار وخلفية البداية محمّلان مبكرًا.
